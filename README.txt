FREE PUBLISHING WITH GITHUB PAGES
1. Sign in/create a free account at https://github.com/
2. Create a PUBLIC repository named umm-website.
3. Upload BOTH index.html and umm-logo.png to the repository's root folder.
4. Go to Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes; GitHub will show the published address on the Pages screen.
8. Open the address on your phone and test both contact buttons.

Keep the two website files together in the same repository folder.
A GitHub Pages address is free; a custom domain is optional and costs extra.
